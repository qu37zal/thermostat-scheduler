# Smart Thermostat Scheduler Frontend

This is the frontend part of the Smart Thermostat Scheduler project, built using React and TypeScript.

## Project Structure

- `src/`: Contains the source code for the React application.
  - `App.tsx`: Main component that renders the application.
  - `index.tsx`: Entry point for the React application.
  - `components/`: Contains React components.
    - `HelloWorld.tsx`: A simple component that displays a "Hello World" message.
- `public/`: Contains static files.
  - `index.html`: HTML template for the React application.
- `package.json`: Configuration file for the frontend npm project.
- `tsconfig.json`: TypeScript configuration file for the frontend.

## Getting Started

1. **Install Dependencies**: Run `npm install` in the `frontend` directory to install the required packages.
2. **Run the Application**: Use `npm start` to start the development server. The application will be available at `http://localhost:3000`.

## Building for Production

To create a production build, run `npm run build`. The build artifacts will be stored in the `build` directory.
